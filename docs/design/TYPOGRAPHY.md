# FORM/TECH typography and wordmark

The reference's central wordmark uses extended geometric lettering and a strong diagonal slash. Its original font/source file was not supplied. `resources/js/components/wordmark.tsx` recreates that direction with original SVG paths: squared letterforms, a wide silhouette and a prominent slash. It is code-native artwork, with a text alternative on each home link, rather than a raster crop of the supplied screenshot. Header, footer and staff screens share the same mark.

The black utility bar uses **Arial/Helvetica sans-serif**, with medium uppercase lettering, left-aligned editable demo copy and desktop Search/Bag controls at the right. Owner feedback on 2026-10-30 identified the previous Barlow Condensed treatment as too small and narrow compared with the reference. The corrected bar is 38px high at 1024px and scales proportionally to roughly 54px at 1440px. White navigation labels use the same sans-serif direction. On mobile the Bag remains in the white header and Search remains in the menu. The previously bundled Barlow font source/license are preserved below.

Font source: [Google Fonts Barlow Condensed](https://github.com/google/fonts/tree/main/ofl/barlowcondensed), downloaded 2026-10-29. Font source: `resources/fonts/barlow-condensed-semibold.ttf`, bundled by Vite into a versioned public asset. Copyright: The Barlow Project Authors, SIL Open Font License 1.1; the complete license is included at `public/fonts/OFL-Barlow-Condensed.txt`. No third-party font request is made by visitors.

UI refinement (2026-10-30): hero/editorial headings use the scoped system stack `Consolas, Liberation Mono, monospace` for the reference's tracked technical lettering. No additional font download or global heading restyle was introduced. The shared SVG artwork is unchanged; its storefront size was adjusted to the complete reference's proportions. Desktop outline Search/Bag links join About in the white header, with utility-band links retained.
